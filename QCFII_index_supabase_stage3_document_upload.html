Upload & pengajuan dokumen QC

Pilih file dokumen asli. File disimpan di Supabase Storage (bucket privat), sedangkan informasi dokumen disimpan di database. File maksimal 20 MB. Format: PDF, Excel, Word, JPG, PNG.

Dokumen belum otomatis menjadi dokumen publik. Owner harus memeriksa dan menyetujuinya terlebih dahulu.
